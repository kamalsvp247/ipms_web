Use only English in code comments, logging, and documentation. No Hindi mixed in.

**Why:** Codebase should be internationally maintainable and consistent. Hindi mixes make code harder to read and maintain across teams.

**How to apply:** When writing comments, log messages, or variable names, use clear Indian/Bangladeshi English. Replace phrases like:
- "use kar rahe hain" → "Using"
- "par" → "on"
- "mein" → "in"
- "ke saath" → "with"
- "banate hain" → "building"
- "kar rahe hain" → "using/attempting"
- "hain" → remove or rephrase
- "mil gya" → "received"
- "re-auth kar rahe hain" → "re-authenticating"
